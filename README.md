# Demenor Game Turbo

Projeto Android inicial inspirado em aplicativos de modo jogo.

## Como abrir
1. Extraia o ZIP.
2. Abra a pasta no Android Studio.
3. Aguarde o Gradle sincronizar.
4. Rode em um aparelho Android 8.0 ou superior.

## Próximas etapas
- serviço de painel flutuante com permissão de sobreposição;
- lista de jogos instalados;
- perfis por jogo;
- estatísticas de sessão;
- atalhos de brilho/volume/rotação;
- integração com APIs específicas quando disponíveis.

O projeto não copia código, marca ou identidade visual proprietária da Xiaomi.
